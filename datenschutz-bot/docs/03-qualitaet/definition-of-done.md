# Definition of Done

Eine Aufgabe ist erst fertig, wenn alles abgehakt ist:

- [ ] Auftragsprotokoll in `docs/00-auftrag/` vorhanden und Ergebnis eingetragen (G1)
- [ ] Code folgt `AGENTS.md`, keine echten Daten im Repo
- [ ] Neue Logik hat Tests; geänderte Erkenner haben Positiv- und Negativ-Test
- [ ] `npm run nachweis` erfolgreich, Nachweis-Datei committet (G12)
- [ ] Datenschutz-Probe bestanden (Teil des Nachweises)
- [ ] Doku aktualisiert: README, Architektur bzw. Entscheidung (ADR), offene Punkte, CHANGELOG
- [ ] Reviews abgelegt und Übersicht aktualisiert, Noten erreicht (G8)
- [ ] OK von Peter vor dem Merge (Auto-Hold)
