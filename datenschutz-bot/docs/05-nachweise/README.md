# Nachweise (Gesetzbuch G12)

Vor jedem Merge `npm run nachweis` ausführen. Das Skript führt Build, Typprüfung, alle Tests und die Datenschutz-Probe aus und legt die echten Ausgaben hier als `JJJJ-MM-TT-<commit>.md` ab. Die Datei wird mit dem Merge committet.

Ein Merge ist nur mit einem bestandenen Nachweis erlaubt. Ist ein Schritt fehlgeschlagen, steht die vollständige Ausgabe in der Datei.
